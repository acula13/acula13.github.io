DADS 6400 · Data Mining for Engineering Applications

Clustering, Time Series
& Text Network Projects

Applied data mining with Python — three major projects
plus module labs on feature engineering and modeling.

Project 1 — Clustering Algorithms

Hands-on clustering on the Economist Democracy Index dataset. Implemented and compared clustering techniques to discover structure in country-level democracy indicators and interpret cluster membership in a real-world context.

Project 2 — Human Activity Time Series Features

Extracted time-series features for human activity monitoring using the Mannheim activity recognition dataset (walking, running, climbing up/down). Computed permutation entropy and complexity across dimensions, delays, and signal lengths; used scatter analysis to find parameters that best separate activity classes.

Project 3 — Keyword Network Analysis

Built weighted keyword adjacency structures from text data and performed network and word-frequency analysis to surface topical structure and important terms.
