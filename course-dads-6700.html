DADS 6700 · Data Management for Analytics

Bluegrass Barrel Co
Database System

End-to-end relational database design for a craft
beverage company — from ER model to analytics.

Overview

This course project designs and implements a full database solution for a fictional craft beverage business, Bluegrass Barrel Co. The system supports production batches, ingredients, products, customers, orders, and feedback — with analytical queries for business insight.

What I built

  • Conceptual & logical models — entities, relationships, keys, and normalization
  • MySQL schema — create tables, constraints, and sample data load scripts
  • Analytical SQL — joins, aggregates, multi-table analytics, inventory and quality queries
  • Python visualization — revenue share, top customers, loyalty tiers, batch yield vs sales
  • Milestone documentation — proposals, implementations, and final presentation assets

Skills demonstrated

ER modeling, SQL DDL/DML, multi-table joins, business analytics queries, data export, and communicating database design decisions to stakeholders.
