# Michael Kenealy — Data Analytics Portfolio

Personal portfolio site for Northeastern University MS Data Analytics Engineering coursework.

Built with **[Massively](https://html5up.net/massively)** by HTML5 UP (CCA 3.0).

## Local preview

```bash
cd portfolio-site
python -m http.server 5500
```

Open http://localhost:5500
